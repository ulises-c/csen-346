# Hugging Face release, staged copies

Nothing here has been uploaded. These are copies of the cards that were staged locally for a
public Hugging Face release, kept in git so they can be reviewed.

| File | What it is |
|---|---|
| `dataset_card_run_outputs.md` | Card (`README.md`) of the run-outputs dataset. Generated by `scripts/build_hf_run_release.py`; do not edit by hand, change the script. |
| `runs.csv` | The run index generated with it. |
| `model_card_socrates-state-classifier-qwen3.5-lora-zh.md` | Card for `results/state-clf-qwen3.5-0.8b-lora-zh/final`. |
| `model_card_socrates-state-classifier-bge-small-zh.md` | Card for `results/state-clf-bge-small-zh/final`. |
| `model_card_socrates-stage-classifier-bert-zh.md` | Card for `results/stage_classifier_v1/final`. |

Rebuild the dataset stage (it reads the run tarballs and, when given, folders with extra
judge scores):

```bash
uv run python scripts/build_hf_run_release.py --archive-dir <run archive folder> \
    [--overlay <folder with RUN/judge_scores/... and RUN/judge_summary_*.json>] \
    --out <stage folder> --overwrite
```

The build stops with a non-zero exit when the staged tree contains an internal host name,
account name or home path, when a run has no turns, or when row counts disagree with a run's
`metrics_summary.json`.

Before uploading, the owner still has to decide: the repository names (suggested names are in
a comment at the top of each model card), the licence of each repository (left as a TODO in
every card), and the status labels in `runs.csv`.
